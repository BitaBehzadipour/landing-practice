# 🎨 Interactive ART Landing Page

A modern and responsive landing page built with **HTML**, **CSS**, and **Vanilla JavaScript**.

This project focuses on building a professional business landing page using modern layout techniques, responsive design principles, and clean UI components.

---

## ✨ Features

- 🏠 Responsive Landing Page Layout
- 🧭 Navigation Bar
- 🎯 Hero Section
- 📖 About / How It Works Section
- 💬 Client Testimonials
- 🖼️ Portfolio Gallery
- 📧 Newsletter Subscription Section
- 📱 Responsive Design
- 🎨 Modern User Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
